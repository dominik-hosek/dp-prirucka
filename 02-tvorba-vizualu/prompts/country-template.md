# Country template generation

## Use case
Prémiová bitmapová stránka turistického průvodce, poměr 2:3, připravená pro digitální distribuci.

## Reference roles
- `REFERENCE_LAYOUT` je hlavní a závazná strukturální reference: zachovej její informační hierarchii, proporce komponent a typ layoutu, nekopíruj však konkrétní texty ani fotografie.
- Profil země níže je závazný vizuální systém cílové země.

## Target
- Země: `{{country_name}}`
- Layout: `{{layout_name}}`
- Vlastnosti: `{{layout_properties}}`
- Vhodný obsah: `{{layout_best_for}}`

## Country system
- Paleta: `{{palette}}`
- Nadpisová typografie: `{{heading_fonts}}`
- Textová typografie: `{{body_fonts}}`
- Ikony a dekorativní motivy: `{{motifs}}`
- Fotografický styl: `{{photo_style}}`
- Výsledný charakter: `{{character}}`

## Page content
Použij přesně tento viditelný český text a žádný další věcný text:

{{page_content}}

Text je záměrně šablonový. Nevymýšlej názvy podniků, adresy, místní fakta ani marketingová tvrzení.

## Constraints
- Zachovej přesný poměr 2:3 a bezpečné okraje.
- Veškerý viditelný text musí být česky, čitelný a bez překlepů.
- Žádná loga, značky, watermarky, anglické popisky, cedule ani smyšlené vlastní názvy.
- Žádné přetečení textu, deformované fotografie nebo vizuální prvky cizí dané zemi.
- Vytvoř jednu jedinou finální variantu této stránky.
