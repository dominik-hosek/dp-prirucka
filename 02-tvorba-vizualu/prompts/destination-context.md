# Destination visual context

Vytváříš prémiový turistický průvodce pro destinaci `{{destination}}` v zemi `{{country}}`.

Průvodce má explicitní obálku, osm dlouhých oddílů a osm samostatných A4 taháčků. Každý oddíl začíná vlastní section-cover stranou. Počet dalších stran vychází z délky obsahu; dlouhou verzi nezkracuj kvůli místu. Obsah děl pouze na hranicích odstavců nebo seznamů.

Používej country systém: `{{country_character}}`. Drž společný vizuální jazyk, ale jednotlivé strany nekopíruj 1:1. Referenční layout určuje hierarchii a komponenty, nikoli konkrétní text či fotografii.
